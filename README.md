# Silon storefront

A responsive, editorial-style fashion storefront built with vanilla HTML, CSS and JavaScript.

## Run locally

From the repository root:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Then open `http://localhost:8000`.

## Included

- Responsive landing page with mobile navigation, category filters, product search, favorites, and a demo shopping bag.
- Scroll reveal and hero animations, with reduced-motion support.
- Semantic page structure, descriptive image alt text, page title and description, Open Graph/Twitter metadata, Organization JSON-LD, favicon, and a crawlable `robots.txt`.

The catalog, prices, newsletter confirmation, and checkout are front-end demo content. Connect a commerce platform and mailing-list provider before accepting orders or signups. Set the real production domain and add a matching canonical URL and sitemap when the site is deployed.
